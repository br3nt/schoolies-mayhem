## Copies and clones
- Forking on GitHub to prepare a pull request is fine; that's how contributions work.
- Otherwise, don't redistribute or republish the game or its code, in whole or part, outside this repository.
- Clones of the game are monitored, whatever form they take. That means copies of this code, and also remakes built without it: reverse-engineered, rebuilt "clean room" from playing it, or generated by an AI tool from a description of it.
- Any additions made in a clone will be ported back into this game.
